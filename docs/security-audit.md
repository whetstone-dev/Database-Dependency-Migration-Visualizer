# Security review for v0.3.2

This is a local source review and verification record, not a certification or a guarantee of complete security. The review covers the Node.js engine/CLI, output formats, creator evaluation viewers, skill installation, dependencies, release packages and GitHub Pages publication. The development preview was stopped. Remote CI, Pages deployment and skills.sh's independent assessments have not run for this revision.

## Confirmed findings and changes

| Finding                                  | Exposure                                                                                                                                                     | Correction and evidence                                                                                                                                                                                                                                                                                                                      |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Output links and input overwrites        | A pre-created hardlink could modify another file; symlinks/junctions could redirect writes; `--out` could replace supplied SQL or JSON.                      | Verify each output path component, reject links/non-regular destinations, write an exclusive private temporary file and atomically replace the destination. Protect source files and distinct artifact destinations before analysis. Node regressions exercise actual hardlinks, Windows junctions, regeneration and unchanged source bytes. |
| Reflected type arguments                 | Comments, recognizable credentials and custom string modifiers in `--to` could enter result/evidence text. Direct library assessment also needed protection. | Share PostgreSQL AST and lexical type normalization across graph and assessment APIs. Remove comments, preserve quoted type identity and reject credential markers or unsupported literal modifiers before evidence creation.                                                                                                                |
| Markdown injection                       | Imported names and IDs could create Markdown links/images and remote requests when rendered.                                                                 | Escape user text in prose/tables and use correctly delimited CommonMark code spans for identifiers. HTML uses text nodes, escaped JSON delimiters and a hash-restricted CSP.                                                                                                                                                                 |
| Catalog expression deparsing             | `pg_get_expr` can call custom data-type output functions while rendering constants, despite a read-only transaction.                                         | Live capture 1.1.0 hashes the stored `adbin::text` node tree. Offline capture 1.0.0 retains its original, version-specific query/hash contract. Authentic historical captures are unchanged.                                                                                                                                                 |
| Unsupported connection routing           | Ignored keyword/URL options could select an unintended connection through driver defaults.                                                                   | Reject unsupported service/hostaddr/routing parameters; normalize supported SSL options and force the existing read-only/timeouts/search-path safeguards. Supported partial DSNs still use normal driver environment defaults.                                                                                                               |
| Catalog evidence amplification           | Rehashing an entire query payload for every object caused quadratic work.                                                                                    | Cache query payload fingerprints and address-specific evidence. Preserve canonical output for the authentic existing capture. This is not a global resource limit.                                                                                                                                                                           |
| Creator evaluation stored HTML injection | Grade values, benchmark fields, attributes and preview URIs could create active HTML or unsafe frames.                                                       | Escape all untrusted display fields, allow only checked local data-URI types, sandbox frames, rebuild spreadsheet tables from inert permitted elements, and fail closed when upstream template anchors change. Remove template external fonts and SheetJS requests.                                                                          |
| Broken real skill installation           | Skills CLI excludes every filename `metadata.json`, removing the high-traffic demo's input.                                                                  | Rename the current input to `workload-profile.json`, update callers, and test the actual pinned Skills CLI in an isolated project with frozen production dependencies. Frozen evaluation inputs retain their historical names.                                                                                                               |
| Publication scope                        | Building from a repository with private local outputs needs an explicit publication boundary.                                                                | Pages uploads only `site/dist`, after checking copied documentation and curated demo bytes against their sources and rejecting unexpected output paths. The workflow is manual-only on main, with SHA-pinned actions and separate deploy permissions.                                                                                        |

The catalog finding follows PostgreSQL's own implementation: `get_const_expr` obtains a type's output function and calls it while deparsing a constant. The corrected discovery query avoids that conversion. [PostgreSQL source](https://github.com/postgres/postgres/blob/REL_18_STABLE/src/backend/utils/adt/ruleutils.c)

## Remaining limits

- A clean dependency audit reports advisories known to the registry at the time of the check. A secret scan and hostile-input tests do not prove the absence of all vulnerabilities or secrets.
- Local verification uses Windows, Node.js 24, PostgreSQL 18 and Chromium. The minimum Node release, other PostgreSQL releases, TLS/production authentication and other browsers are not all exercised locally. CI's configured matrix is separate from observed results.
- Callers trust their filesystem, source directory, explicitly selected connection and installed executable dependencies. The tool cannot prevent another local user from concurrently replacing directories, or make a hostile database/server safe. Partial DSNs retain normal driver defaults.
- General resource exhaustion remains possible with very large inputs. UI limits protect rendering size, not the complete analysis process. Routine bodies, dynamic SQL, runtime consumers and nested/ambiguous column scopes remain partial or unavailable.
- Labels and paths can contain private information even when literals and recognized credential markers are omitted. Review artifacts before sharing. npm locks direct dependencies; the `.skill` installation uses the frozen pnpm lockfile for transitive dependencies.
- Pages must be enabled in repository settings and the reviewed source pushed before a manual deployment. No remote publication is recorded here. skills.sh's external audits are independent of this review. [Skills documentation](https://www.skills.sh/docs)
